# Страница «Противники»

> Актуальная архитектура, сохранения, стили и команды проверки описаны в [PROJECT_DOCUMENTATION.md](PROJECT_DOCUMENTATION.md). Этот файл сохраняет дополнительные заметки по разделу; старые списки проверок и этапы реализации не являются текущим отчётом аудита. См. [CODE_REVIEW_REPORT.md](CODE_REVIEW_REPORT.md).

Маршрут: `#/enemies`. Данные: 8 локаций, 76 противников, связь через `enemy_location_id`. Боссы не включены: источником по заданию служит `Enemies.json`.

## Реализовано

- Выбор локаций с оригинальными постерами и плавная смена фона после загрузки изображения.
- Единое состояние выбранной локации, противника и режима; выбор сохраняется при переходах по разделам до перезагрузки страницы.
- Циклическая карусель в обе стороны, 400 мс; предзагрузка двух соседей, ожидание декодирования, блокировка повторного перехода. Управление кнопками и клавишами ←/→ при фокусе внутри центральной области.
- Режим уменьшенного движения, обработка отсутствующей модели, скрытие стрелок для единственного противника и режим локации для пустого списка.
- Динамическая дуга 0–7 способностей; для 6–7 уменьшены рамки, чтобы исключить наложение. На телефонах способности расположены под моделью.
- Переиспользование навигации, здоровья/щита, отображения характеристик, описаний, подсказок и изображений декора.
- Подсказки способностей и эффектов с изображением и параметрами, открытие мышью, фокусом и нажатием; закрытие при смене сущности/режима, Escape и нажатии вне подсказки.
- Два режима правой панели с прокруткой описания и постоянно доступной нижней кнопкой.

## Данные и ресурсы

Исходные JSON и изображения не менялись.

- У всех противников `attack_spead: 1`, в отличие от значений героев около 100. На странице показано исходное `1`, без преобразования героев. Единицы измерения JSON не документирует; при уточнении модели это решение можно изменить в `enemyStatColumns`.
- `spell_damage`, `spell_cooldown`, `building_damage` отсутствуют: показано «—». Присутствующие нули сохраняются.
- `Forge_crash.png` и `Return_lava_hammer.png` демона-кузнеца (ID 29) найдены в `03. Caldera/Skill_images/`.
- `Incorporeality.png` истерзанной души (ID 39) находится в `Game_images/Location_effects/`.
- Эти три соответствия явно записаны в `locationAssets.ts`.
- `Location_effects/Toxic Marshes.png` отсутствует. Кнопка эффекта имеет нейтральный знак «?», доступное название и полное описание в подсказке; запрос несуществующего изображения не отправляется.
- В текущих данных у противников 0–3 способности. Случаи 4–7 проверены синтетическими тестами геометрии.

## Проверки и ограничения

- `node --test tests/*.test.ts`: 44 теста проходят (12 новых, 32 существующих).
- `npm.cmd run lint`: проходит.
- `npm.cmd run build`: TypeScript и Vite проходят. Vite предупреждает о JS-чанке больше 500 кБ; сборка успешна.
- Новых зависимостей нет.
- Проверены существование всех фонов, постеров, моделей и иконок, кроме документированного отсутствующего файла.
- Автоматизированные тесты проверяют слой данных, переходы выбора/режима и геометрию; они не являются браузерными тестами анимации или быстрых кликов.
- Открыть страницу для визуальной проверки не удалось: подключённый browser-интерфейс отсутствует; доступ к локальному Chrome через Computer Use завершился сообщением `Computer Use app approval timed out`.
- Остаётся визуально проверить оба режима на 1648×928, 1920×1080, 1600×900, 1366×768 и узком экране, а также анимацию, быстрые клики и подсказки в браузере. Нужна оригинальная иконка `Toxic Marshes.png` для полного комплекта ресурсов.
