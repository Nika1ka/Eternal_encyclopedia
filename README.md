# Eternal — энциклопедия

Интерактивный справочник по Eternal Battle и конструктор сборок героя.

- **Герои** — характеристики, способности и варианты их улучшений.
- **Экипировка** — каталог предметов, выбор снаряжения и уровней.
- **Таро** — расклад Арканов, их бонусы и влияние на сборку.
- **Противники** — враги, боссы, способности и локации.

Характеристики пересчитываются при изменении сборки. Сборки сохраняются в браузере между посещениями. Сайт не симулирует бой.

Разработано на React, TypeScript и Vite. Инструкции по запуску, проверкам и публикации на GitHub Pages — в [документации проекта](PROJECT_DOCUMENTATION.md).
