# Игровая энциклопедия

Добро пожаловать в интерактивный справочник по игре и конструктор сборок героев. Все значения рассчитываются автоматически в зависимости от экипированных карт Таро, предметов и выбранного уровня героя.
Сайт создан для удобного балланса игровых предметов и Таро - будущая игра пока ещё находится в разработке.
Имейте в виду, что многие из присутствующих графических элементов являются референсами и в будущем будут (или уже были) изменены. Все игровые элементы на страничке созданы и принадлежат автору-разработчику.

1. **Герои** - характеристики, способности и варианты их улучшений;
2. **Экипировка** - каталог предметов, выбор снаряжения и уровней;
3. **Таро** - расклад Арканов, их бонусы и влияние на сборку;
4. **Противники** - враги, боссы, способности и локации.

Характеристики пересчитываются при изменении сборки.
Сборки сохраняются в браузере между посещениями. Сайт не симулирует бой.

Интерактивный сайт разработан на React, TypeScript и Vite.
